# امکانات JavaidPanel — وضعیت پیاده‌سازی

**تاریخ بازبینی:** 2026-11-06 · **نسخه سورس:** 1.1.106-dev

### تعریف وضعیت‌ها

- **موجود در سورس:** فایل یا پیاده‌سازی قابل مشاهده است؛ لزوماً تست نشده.
- **آزمایش ایستا:** نحو/هش/سناریوی آفلاین تست شده، نه اجرای سرویس روی VPS.
- **در توسعه:** طراحی یا کد مقدماتی وجود دارد، ولی API یا تست واقعی کامل نیست.
- **برنامه آینده:** هنوز پیاده‌سازی شده نیست.

## خانواده پروتکل‌ها

**وجود پروتکل در هسته upstream به معنی پشتیبانی نهایی JavaidPanel نیست.** پروتکل باید روی VPS واقعی، در حالت اتصال/قطع، مدیریت کانفیگ و پردازش مصرف تست شود. برای VLESS، VMess، Trojan، Shadowsocks، WireGuard، SSH، OpenVPN، L2TP، IKEv2، TUIC، Hysteria2 و دیگر موارد نباید وضعیت عملیاتی ساختگی نمایش داده شود.

## معیار پذیرش

هر قابلیت وقتی از «در توسعه» به «آماده» تغییر می‌کند که: کد اجراشدنی، تست واحد، تست یکپارچه‌سازی، راهنمای پشتیبانی، بازگشت امن و در صورت شبکه‌ای‌بودن **تست سرور واقعی** داشته باشد.

## واسط مدیریت نود (نسخه 1.1.106-dev)

یک داشبورد وب مستقل برای API کنترلر اضافه شده که در مسیر loopback `/admin/nodes` قابل مشاهده است: ثبت نود، نمایش توکن یک‌بارمصرف و دستور نصب، فهرست heartbeat و ابطال. **اتصال به Gateway اصلی، کنترل تونل‌ها و آزمون دو VPS هنوز انجام نشده است.** [راهنمای داشبورد](NODE_DASHBOARD.md).
