# معماری JavaidPanel

## اجزای موجود در مخزن اصلی
- `install.sh`: نصب‌کنندهٔ سرور مرکزی
- `node-agent-install.sh`: نصب‌کنندهٔ عامل نود
- `docker-compose.production.yml`: تعریف سرویس‌های کانتینری
- `docs/index.html`: لایهٔ مستقل و ایستای معرفی عمومی

## محدودهٔ این بازطراحی
این تغییر ظاهری و مستندسازی است؛ هیچ API، موتور VPN، احراز هویت یا اتصال نود جدیدی را صرفاً با افزودن HTML فعال نمی‌کند.

## هدف توسعه
مدیریت کاربران و سهمیه‌ها، نودهای توزیع‌شده، پایش سرور، تنظیمات و پشتیبانی چند پروتکل باید با قراردادهای پایدار و تست‌های انتهابه‌انتها اجرا شوند.

نگهداری رازها و کلیدهای سرور باید سمت سرور بماند. اجرای اسکریپت دانلودشده و خدمات دارای دسترسی بالا باید با کنترل امنیتی انجام شود.
