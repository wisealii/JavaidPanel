# وضعیت واقعی قابلیت‌ها

این جدول «وجود فایل» را از «پشتیبانی واقعیِ آزموده‌شده» جدا می‌کند:

| بخش | یافته | اعتبارسنجی |
|---|---|---|
| نصب‌کننده | `install.sh` در مخزن فعلی وجود دارد | اجرای VPS آزمایش نشده |
| عامل نود | `node-agent-install.sh` وجود دارد | اتصال چندسروری آزمایش نشده |
| Docker Compose | `docker-compose.production.yml` وجود دارد | اجرای سرویس‌ها آزمایش نشده |
| پروتکل‌های VPN | در README قبلی معرفی شده بودند | نیازمند تست مستقل هر پروتکل |
| تونل‌های بین سروری | در README قبلی معرفی شده بودند | نیازمند تست اتصال واقعی |
| سازگاری Ubuntu / Debian | در README قبلی ادعا شده بود | نیازمند ماتریس تست هر نسخه |
| صفحهٔ معرفی | HTML و CSS ایستای JP UI | قابل بررسی در GitHub Pages |

## معیار انتشار نسخهٔ پایدار
- بازبینی امنیتی، تست نصب و به‌روزرسانی، و برنامهٔ rollback
- تست با VPS تازه و گزارش قابل بازتولید
- بررسی TLS، احراز هویت، نودها و کنترل دسترسی
- بررسی عملی هر پروتکل و روش تونل

**هیچ دادهٔ پیش‌نمایش سایت، مانیتورینگ واقعی سرور نیست.**
