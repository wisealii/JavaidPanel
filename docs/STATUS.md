# وضعیت واقعی — 1.1.111-dev

## نصب
- **Bootstrap یک‌دستوری**: پیاده‌سازی شد؛ `install.sh` کد اصلی را فقط با هش SHA-256 صحیح اجرا می‌کند.
- **هسته پایه**: فایل `installer/core.sh` همان AlirezaPanel 2.8.0 مشتق از VPN-UI و AdGuard Home است، با مجوز GPL.
- **تست ایستا**: صحت Bash و استخراج نحو ماژول‌های Python از طریق `--self-test` قابل بررسی است.
- **نصب واقعی VPS**: هنوز انجام نشده.

این نسخه **نصب‌پذیر آزمایشی** است و نباید «پنل جاوید کامل و پایدار» معرفی شود.

## بازبینی 1.1.111-dev

پیش‌نیازهای نصب و مسیرهای تعمیر/SSL قبل از دانلود چک می‌شوند. آزمون‌های CI صحت سنجی ورودی و سورس را بررسی می‌کنند؛ نصب واقعی VPS، عملکرد پروتکل‌ها و SSL هنوز آزموده نشده‌اند.

## توسعه Javid Node و SSL — 1.1.111-dev

- API واقعی JSON برای ایجاد توکن نود، claim، heartbeat، لیست و ابطال ساخته شده است.
- عامل مستقلی برای ارسال heartbeat امضاشده اضافه شد؛ نود فقط بعد از heartbeat تأییدشده آنلاین نمایش داده می‌شود.
- توکن‌های ثبت یک‌بارمصرف با انقضا، جلوگیری از replay، HMAC و دیتابیس SQLite دارای تست‌های مستقل‌اند.
- ابزار تعاملی SSL پنج‌مرحله‌ای اضافه شده است؛ اخذ گواهی و HTTPS واقعی هنوز روی VPS آزموده نشده است.
- API هنوز به مدیریت کاربران/پنل مرکزی، مبدل‌های تونل و موتور VPN متصل نیست؛ mTLS و گردش کلید هنوز تکمیل نشده‌اند.

[راهنمای API](JAVID_NODE_API.md) · [راهنمای SSL](SSL_QUICKSTART.md)

## مرحله چهارم: مدیریت نود از رابط وب محلی

- صفحهٔ واقعی `/admin/nodes` به API کنترلر وصل شد، با احراز Bearer و دسترسی فقط از loopback/SSH.
- ثبت IP/نام، تولید توکن و دستور نصب، فهرست وضعیت، آخرین heartbeat و ابطال در رابط وجود دارد.
- این **یک UI مستقل برای کنترلر است، نه ادغام داخل Gateway اصلی**. دسترسی عمومی و تست دو VPS هنوز مجاز/تأیید نشده است.

## کنترل ارتقای امن · 1.1.111-dev
- ابزار `tools/upgrade-control-plane.py`: plan، اعمال کنترل‌شده، حفظ کد پیشین و بازگشت پس از خطای restart/health.
- اسکریپت فقط کد کنترلر مستقل Javid Node را ارتقا می‌دهد؛ **Gateway پایه، پروتکل VPN و دیتابیس را تغییر نمی‌دهد**.
- تست‌های فایل‌سیستم موقت در CI اضافه شدند؛ تست عملی روی VPS انجام نشده است.
- برای یکپارچگی ورود مدیر پنل، نیاز به دسترسی به سورس و قرارداد احراز هویت واقعی Gateway وجود دارد.

## آزمون آمادگی انتشار · 1.1.111-dev

- نسخهٔ داخلی نصب‌کننده با فایل VERSION یکسان شد.

- نصب واقعی VPS، صدور SSL، ورود حساب مدیر، اتصال دو نود، پروتکل‌های اصلی و بازیابی داده هنوز باید جداگانه آزموده شوند.

## اصلاح مسیر استقرار جایگزین

طرح Docker Compose ناقص از ریشه مخزن حذف شد و به [بایگانی طرح](EXPERIMENTAL_COMPOSE.md) انتقال یافت. **هیچ روش کانتینریِ آماده تولیدی معرفی نشده است**؛ نصب اصلی فقط از مسیر آزمایشی پین‌شده انجام می‌شود.

## P0: پیش‌نیازهای حیاتی SSL

در نسخه 1.1.111-dev، راهنمای SSL در نبود DNS معتبر A/AAAA یا ناتوانی بررسی وضعیت TCP 80 ادامه نمی‌دهد؛ تست‌های آفلاین جدید ثبت شده‌اند. **این اصلاح به معنی دریافت موفق Let's Encrypt یا راه‌اندازی HTTPS روی VPS نیست.** [تایم‌لاین اولویت‌ها](PRIORITY_TIMELINE.md).

فهرست دقیق سورس و لایه‌ها در [CURRENT_FEATURES_AUDIT.md](CURRENT_FEATURES_AUDIT.md) ثبت شد. همه ادعاهای عملیاتی به موفقیت تست واقعی VPS وابسته‌اند. نصب بدون ترمینال و بدون تعیین TLS mode صریح متوقف می‌شود تا گواهی خودامضاشده به‌عنوان انتخاب پیش‌فرض ناخواسته تولید نشود.

## ابزار تست بعد از نصب · 1.1.111-dev

`tools/vps-postinstall-smoke.py --run` روی VPS آزمایشی می‌تواند سرویس‌ها، دیتابیس، مجوز فایل‌ها و سلامت داخلی Gateway را بررسی کند. **این ابزار هنوز روی VPS واقعی اجرا نشده و تست SSL بیرونی، ورود مدیر و پروتکل‌ها همچنان دستی و انجام‌نشده‌اند.** [مراحل اجرا](VPS_SMOKE_TEST.md).
