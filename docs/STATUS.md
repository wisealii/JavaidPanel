# وضعیت واقعی JavaidPanel

نسخه سورس: **1.1.102-dev**.

## یافتهٔ امنیتی و عملیاتی

نصب‌کنندهٔ قبلی پنل به‌جای اجرای بک‌اند یک فرآیند ماندگارِ بدون سرویس واقعی اجرا می‌کرد. نود قبلی نیز صرفاً پیام اتصال را چاپ می‌کرد و daemon واقعی با احراز هویت mTLS نداشت.

در نسخهٔ حاضر این رفتار حذف شده است. `install.sh --install` و نصب عامل نود تا آماده‌بودن backend قابل آزمون **مسدود** هستند. فرمان preflight بی‌خطر و صدور مستقل گواهی در دسترس است.

| بخش | وضعیت |
|---|---|
| رابط معرفی GitHub Pages | ایستا، آماده نمایش |
| بررسی سیستم سرور | پیاده‌سازی شده (خواندنی) |
| دریافت مستقل گواهی با Certbot | فرمان واقعی؛ نیازمند DNS و پورت 80 |
| پنل مدیریتی زنده | در مخزن فعلی موجود نیست |
| ویزارد نصب و مدیر اولیه | هنوز پیاده‌سازی نشده |
| مدیریت سرویس VPN | موجود نبودن هسته واقعی تأیید شد |
| ثبت و همگام‌سازی نود | هنوز پیاده‌سازی نشده |
| نصب کامل با یک دستور | هنوز آماده نیست |
| آزمون واقعی VPS | انجام نشده |

**هیچ ادعای موفقیت نصب یا مدیریت واقعی کاربران/پروتکل‌ها از این فهرست نباید استنباط شود.**
