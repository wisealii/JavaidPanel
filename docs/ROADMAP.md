# نقشه راه JavaidPanel

**مبنای صداقت انتشار:** هیچ مرحله‌ای تا اجرای آزمون واقعی قابل اتکا «تکمیل‌شده» نیست.

| مرحله | هدف | شرط پذیرش |
|---|---|---|
| ۰ · وضعیت موجود | معرفی مستقل، راهنما، نصب با هش و تست CI | CI موفق |
| ۱ · نصب آزمایشی واقعی | نصب روی VPS تازه، SSL، مدیر اولیه، سلامت سرویس | لاگ، URL و تست HTTPS |
| ۲ · Javid Node | کنترلر، توکن یک‌بارمصرف، عامل و heartbeat | تست دو VPS، حذف/ابطال |
| ۳ · کاربران و اشتراک | REST API، تراکنش، RBAC و تیکت | تست API، امنیت، audit |
| ۴ · پروتکل‌ها | ماتریس پشتیبانی و اجرای واقعی هر موتور | اتصال واقعی و قطع/وصل هر روش |
| ۵ · تونل‌ها | WireGuard، GRE/IPIP، VXLAN، SSH reverse و رله‌ها | نصب/حذف و recovery دوطرفه |
| ۶ · انتشار | backup/restore، upgrade و rollback | تست ارتقا و بازیابی با داده |
| ۷ · نسخه پایدار | مستندات کامل، تست فشار و امنیت | گزارش مستقل و release notes |

## موضوعات مهم قبل از انتشار

- جداسازی کامل Branding از شناسه‌های سرویس: **rename داخلی** را فقط با migration تست‌شده انجام دهید.
- خارج‌کردن secretها از shell history و logها.
- جلوگیری از نمایش آمار نمونه به‌عنوان زنده.
- اضافه‌کردن تست نصب و recovery در VM.
- مشخص‌کردن وضعیت واقعی هر پروتکل و تونل در UI و API.
- تهیه جدول نسخه‌های OS/CPU آزمایش‌شده.
