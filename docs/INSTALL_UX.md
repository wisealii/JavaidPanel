# تجربهٔ نصب هدف JavaidPanel

این سند مراحل موردنیاز برای ساخت **نصب حرفه‌ای مستقل JavaidPanel** را شرح می‌دهد. مرحله‌های زیر هنوز به‌طور کامل در سورس اجرا نشده‌اند.

## فلو نهایی موردنظر

1. یک دستور برای دریافت و تأیید نصب‌کننده، با انتخاب نسخه و SHA-256.
2. Preflight: بررسی OS، معماری، RAM، فضای آزاد، ساعت، DNS، پورت‌ها و نصب قبلی.
3. نصب هستهٔ واقعی، ساخت دیتابیس، راه‌اندازی سرویس و تأیید Health Check.
4. بازشدن لینک setup یک‌بارمصرف و منقضی‌شونده.
5. ویزارد وب: دامنه، HTTPS، ساخت حساب مدیر و رمز امن.
6. صدور/تمدید گواهی Let's Encrypt و بارگذاری مجدد بدون قطعی.
7. نمایش URL نهایی پنل؛ **نمایش رمز عبور فقط یک‌بار در کانال امن** و هرگز در log عمومی.
8. بخش «اتصال نود»: مشخصات سرور، توکن یک‌بارمصرف، نصب عامل روی VPS دیگر و سلامت واقعی.
9. CLI مستقل برای start/stop/status/logs/update/backup/restore/uninstall.

## معیار پذیرش

- URL ورود پاسخ HTTPS معتبر بدهد، و credentials واقعاً کار کنند.
- نصب مجدد داده‌های پیشین را بدون رضایت تغییر ندهد.
- کلیدهای مدیر و دیتابیس با دسترسی محدود نگهداری شوند.
- توکن setup و توکن نود منقضی شوند و دوباره مصرف نشوند.
- شکست نصب به rollback یا پیام تشخیصی دقیق ختم شود.
- تست واقعی VPS و ثبت گزارش برای هر سیستم‌عامل وجود داشته باشد.
