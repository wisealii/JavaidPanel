# بازبینی هویت JavaidPanel — تغییر پیشنهادی

مبنا: `1.1.113-dev`، Commit `0d23d7458801d1b984d5d660ad0491cefed125ce`.
مرتبط: [Issue 26](https://github.com/wisealii/JavaidPanel/issues/26).

این PR اولین اصلاح محدود در لایه نمایش است؛ نسخه و نصب VPS را ارتقا نمی‌دهد.
رنگ قرمز و نشان JP پیشنهاد قابل بازبینی‌اند و طرح نهایی تأییدشده مالک محسوب نمی‌شوند.
داشبورد تازه، API، نقش یا موتور جدید ایجاد نمی‌شود.

## تغییر و سازگاری

- عنوان مرورگر، برچسب برند، لوگو/favicon و عنوان پوسته DNS/Nodes/Content از هویت JavaidPanel استفاده می‌کنند.
- متغیرهای رنگ تأکیدی در پوسته فعلی عوض می‌شوند؛ ساختار فرم‌ها و چیدمان باقی می‌ماند.
- نام سرویس، CLI، مسیرهای فایل، `window.ALIREZA`، هدر و مسیر `_alireza` برای سازگاری حفظ می‌شوند.
- رابط بومی AdGuard، متن کد/تنظیمات، جدول داده‌ها و محل‌های attribution نباید تغییر نام داده شوند.
- نسخه query فایل‌های برند/CSS/لوگو تغییر می‌کند تا کش نصب قبلی پوسته قدیمی را نگه ندارد.
- checksum واقعی هسته در bootstrap و CI هماهنگ می‌شود.
- فایل LICENSE، SOURCES و متن مجوز embedded تغییر نمی‌کنند.

## آزمون‌ها

دو تست برند روی مبنا شکست خوردند؛ پس از اصلاح چهار تست فایل
`tests/test_gateway_branding.py` موفق شدند. تست Gateway متد واقعی embedded را اجرا می‌کند
و حفظ input، JavaScript تنظیمات، مسیر قبلی و HTML بومی DNS را بررسی می‌کند.
۱۲ تست bootstrap، از جمله مسیر pipe معتبر و رد checksum مخدوش، و self-test هسته موفق شدند.

این نتایج جایگزین آزمون تصویری نیستند. بررسی تمام صفحات، موبایل/دسکتاپ، فارسی/انگلیسی،
RTL، روشن/تاریک، نشست منقضی و کش در مرورگر روی نسخه پیشنهادی هنوز انجام نشده است.
CI و این آزمون‌های مرورگری باید پیش از استقرار بررسی شوند.

## گزارش VPS بدون اسرار

در بررسی فقط‌خواندنی ۲۰۲۶-۱۱-۱۰ سه سرویس اصلی فعال بودند.
هش فایل‌های نصب‌شده `brand.js`، `theme.css` و `gateway.py` دقیقاً با خروجی embedded مبنا مطابقت داشت.
بنابراین اصلاح پیشنهادی هنوز روی VPS نیست. هیچ تنظیم، رمز، نود یا کاربری در این مرحله تغییر نکرد.

## بازگشت

تا پیش از Merge، بستن PR هیچ اثری روی VPS ندارد. بازگشت سورس باید کل Commit، شامل checksumهای
bootstrap و workflow، را با هم revert کند. این سند مجوز اجرای repair یا استقرار نیست.
قبل از استقرار و rollback واقعی، بکاپ، طرح بازگشت و تأیید مالک لازم است.
