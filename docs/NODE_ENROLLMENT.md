# طرح فنی «اتصال نود» — Javid Node

در نسخه 1.1.105-dev **API اولیه و عامل گزارش سلامت اجراشدنی‌اند**؛ این سند همچنان معماری هدف اتصال کامل نود و mTLS را شرح می‌دهد. [راهنمای اجرای API](JAVID_NODE_API.md).

## فلو مورد انتظار

```text
مدیر پنل → ثبت مشخصات نود → ساخت enrollment کوتاه‌عمر
    ↓
دریافت شناسه + دستور bootstrap برای VPS دیگر
    ↓
عامل نود → HTTPS معتبر → ارسال توکن + nonce + CSR
    ↓
سرور مرکزی: بررسی هش توکن، انقضا، مصرف‌نشدن، مجوز مدیر
    ↓
اتمی: ابطال توکن و صدور هویت عامل با گواهی/کلید مستقل
    ↓
heartbeat امضاشده + گزارش نسخه و ظرفیت → نمایش وضعیت زنده
```

## فرم در پنل

| فیلد | توضیح |
|---|---|
| عنوان نود | نام انسانی، مانند «آلمان ۰۱» |
| IP / hostname | آدرس سرور قابل دسترس؛ validate بدون اجرای کد shell |
| پورت | عدد 1–65535؛ پورت مجاز باید با کنترلر سازگار باشد |
| منطقه/برچسب | فیلتر UI، فاقد نقش امنیتی |
| مدت اعتبار ثبت | پیش‌فرض پیشنهادی ۱۰ دقیقه، حداکثر ۳۰ دقیقه |
| دسترسی‌های عامل | فقط نقش node؛ بدون دسترسی مدیر/خرید |
| روش نصب | اولویت با اجرای فرمان روی VPS توسط خود مدیر؛ SSH اتومات فقط با رضایت صریح |

## API جاری و endpointهای آینده

- `POST /api/v1/nodes/enrollments` — فقط مدیر مجاز؛ پاسخ شامل `enrollment_id`، token یک‌بارمصرف و `expires_at`.
- `POST /api/v1/nodes/claim` — ثبت هویت از کانال TLS؛ توکن یک‌بارمصرف و قابل ابطال.
- `GET /api/v1/nodes` — فهرست و وضعیت، بدون رازها.
- `POST /api/v1/nodes/{id}/revoke` — ابطال هویت عامل.
- `POST /api/v1/nodes/{id}/rotate` — چرخش اعتبارنامه پس از احراز مجدد.

موارد لازم: احراز هویت مدیر و CSRF/CORS، rate limiting، ثبت audit، تراکنش اتمیک، انقضا، clock skew، TLS certificate validation، مدیریت replay، و تست موازی برای مصرف دوباره توکن.

### فرمان نمونهٔ پیشنهادی

فرمان زیر **صرفاً نمایش ساختار پیشنهادی است، قابل اجرا نیست**:

```text
javid-node join --panel https://panel.example.org --enrollment-id <ID> --token-file /root/javid-token
```

**هیچ توکن واقعی را در query-string URL، لاگ سرویس، تاریخچه shell یا اسکرین‌شات منتشر نکنید.** این مدل بر کپی فرمان و فایل توکن خصوصی تأکید دارد.

## معیار پذیرش

- Claim موفق دقیقاً یک بار؛ اجرای مجدد و توکن منقضی حتماً رد شود.
- احراز هویت مدیر و عامل مستقل باشد.
- کنترلر heartbeat جعلی را نپذیرد.
- با قطع شبکه، وضعیت «قطع» شود، نه اینکه تا ابد آنلاین بماند.
- حذف نود کلید آن را باطل کند.
- نصب و حذف روی **دو VPS آزمایشی** قابل بازتولید باشد.
