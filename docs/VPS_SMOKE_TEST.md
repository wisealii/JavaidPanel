# تست پس از نصب JavaidPanel روی VPS آزمایشی

**این ابزار فقط قابلیت‌های موجود در هسته JavaidPanel را بررسی می‌کند** و هیچ سرویس یا فایل را تغییر نمی‌دهد. نسخهٔ توسعه‌ای 1.1.111-dev؛ هنوز نصب واقعی VPS و کارکرد پروتکل‌ها در این نوبت تأیید نشده است.

## قبل از اجرای نصب

برای Ubuntu 24.04 یا Debian 12/13 روی x86_64 با systemd، دامنه/SSL و بکاپ پیش‌نیازها را مطابق [راهنمای نصب](INSTALLATION.md) آماده کنید. ابتدا روی **VPS تازه و غیرتولیدی** تست کنید.

## بررسی کد ابزار بدون دسترسی سرور

```bash
python3 tools/vps-postinstall-smoke.py --check
```

## بعد از نصب در VPS آزمایشی

پس از اینکه Gateway و DNS/VPN بالا آمدند، داخل مخزن جاوید پنل:

```bash
sudo python3 tools/vps-postinstall-smoke.py --run
```

برای خروجی JSON قابل بایگانی، **بدون نمایش اسرار**:

```bash
sudo python3 tools/vps-postinstall-smoke.py --run --json
```

ابزار موارد زیر را کنترل می‌کند: وجود فایل‌های نصب‌شده، محدودبودن مجوز فایل دسترسی، فرمت پیکربندی Gateway، quick_check خواندنی SQLite، فعال‌بودن سرویس‌های systemd، نتیجهٔ health probe داخلی و علامت‌گذاری آزمون‌های دستی. هیچ رمزی یا توکنی را چاپ نمی‌کند.

### معنی نتیجه

- PASS: بررسی فنی **محلیِ همان مورد** موفق بوده.
- FAIL: مشکل اثبات‌شده محلی وجود دارد و قبل از ادامه باید اصلاح شود.
- MANUAL: تست حقیقی هنوز نیازمند انسان/VPS دوم/دامنه یا کلاینت است؛ نباید به‌عنوان PASS شمرده شود.

در هر شرایط، حتی با همه PASSها، باید **گواهی TLS معتبر از خارج VPS، ورود مدیر، اتصال VPN کلاینت و بازیابی بکاپ روی VPS دوم** مستقلاً بررسی شوند.

**محدودیت ابزار:** صحت عملکرد پروتکل‌ها، تمدید گواهی، سلامت نودها و امکان restore را تأیید نمی‌کند؛ SQLite quick_check هم تضمین سلامت کامل کاربردی دیتابیس نیست.
