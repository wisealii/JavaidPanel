# راهنمای دامنه و SSL / TLS

JavaidPanel باید با HTTPS معتبر ارائه شود. در نسخهٔ کنونی، مسیر دریافت گواهی در **هسته نصب پایه** وجود دارد، اما روی دامنه و VPS واقعی در این توسعه تست نشده است.

## پیش‌نیاز دریافت Let's Encrypt

1. یک دامنه یا زیردامنه تحت کنترل خودتان داشته باشید.
2. رکورد DNS A/AAAA صحیح به IP عمومی VPS اشاره کند.
3. پورت‌های لازم برای روش اعتبارسنجی ACME در فایروال/پروکسی قابل دسترس باشند.
4. برنامهٔ دیگری پورت مورد نیاز را اشغال نکرده باشد یا روش challenge سازگار انتخاب شود.
5. ساعت و DNS سرور درست باشد.

## نصب / پیکربندی

برای نصب روی **VPS آزمایشی تازه**:

```bash
curl -fsSL https://raw.githubusercontent.com/wisealii/JavaidPanel/main/install.sh | sudo bash
```

در جریان نصب، گزینه‌های مربوط به دامنه و TLS هسته پایه نمایش داده می‌شوند.

برای مدیریت گواهی **پس از نصب موفق**:

```bash
curl -fsSL https://raw.githubusercontent.com/wisealii/JavaidPanel/main/install.sh | sudo bash -s -- --ssl
```

## خطاهای متداول

- **DNS mismatch:** دامنه به VPS اشاره ندارد یا cache هنوز تازه نشده.
- **ACME timeout:** پورت بسته، CDN/Reverse proxy ناسازگار یا listener دیگری فعال است.
- **نامعتبر بودن گواهی:** دامنه دیگری در browser وارد شده یا chain ناقص است.
- **تمدید ناموفق:** مسیر renewal یا reload سرویس ناقص است.

**هشدار:** صدور موفق گواهی لزوماً به معنی بالا آمدن پنل نیست. عملکرد HTTPS باید با مرورگر و زنجیره گواهی معتبر جداگانه تأیید شود.
