# SSL / TLS در JavaidPanel

برای کاربران، یک راهنمای **پنج‌مرحله‌ای تعاملی** اضافه شده است:

**[راهنمای سریع SSL و Let's Encrypt](SSL_QUICKSTART.md)**

روی سروری که سورس مخزن را دریافت کرده است:

```bash
sudo bash tools/ssl-wizard.sh
```

ابزار، دامنه و ایمیل را می‌پرسد، وضعیت DNS و پورت TCP 80 را بررسی می‌کند و پس از تأیید، Certbot را برای دریافت گواهی اجرا می‌کند. **این ابزار وب‌سرور را راه‌اندازی نمی‌کند و روی VPS واقعی هنوز آزمایش نشده است.**

اگر هسته پایه JavaidPanel نصب شده، دستور مدیریت SSL نصب‌کننده هم در دسترس است:

```bash
curl -fsSL https://raw.githubusercontent.com/wisealii/JavaidPanel/main/install.sh | sudo bash -s -- --ssl
```

روش مناسب را با توجه به استقرار واقعی انتخاب کنید؛ دو روش را بدون بررسی روی یک دامنه همزمان اجرا نکنید.
