# انتشار صفحه اختصاصی JavaidPanel

بعد از ادغام این تغییرات در شاخه `main`:

1. مخزن را در GitHub باز کنید.
2. به `Settings → Pages` بروید.
3. در بخش `Build and deployment` گزینهٔ `Deploy from a branch` را انتخاب کنید.
4. شاخه `main` و پوشه `/docs` را انتخاب کنید و Save بزنید.
5. URL منتشرشده را در تنظیمات About مخزن ثبت کنید.

صفحهٔ HTML در `docs/index.html` قرار دارد. کارت‌ها و آمار نمایشی هستند و به پنل واقعی متصل نیستند.

**نکته:** GitHub Pages طراحی اختصاصی دارد اما رنگ خود صفحه استاندارد github.com قابل تغییر برای همهٔ بازدیدکنندگان نیست.

## لینک تاریخچه نسخه‌ها

صفحه [VERSIONS.md](VERSIONS.md) فهرست نسخه‌ها و مسیر هر آرشیو را نمایش می‌دهد و [versions.json](versions.json) داده ساختاریافته برای نمایش ماشینی است. این فهرست شامل لینک‌های Tag/Release جعلی نیست.
