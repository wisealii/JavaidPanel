# ارتقای ایمن کنترلر Javid Node — 1.1.107-dev

**دامنه این ابزار:** فقط سورس سرویس `javid-node-control.service` را ارتقا می‌دهد؛ هیچ تغییری در دیتابیس، توکن‌ها، فایل تنظیمات، گواهی‌ها، وب‌سرور، عامل‌های نصب‌شده یا سرویس پایه VPN ایجاد نمی‌کند.

## قبل از شروع

- از VPS آزمایشی و فایل‌های `/etc/javid-panel` و پایگاه داده آن بکاپ امن تهیه کنید.
- فایل‌های جدید را از ریپازیتوری رسمی JavaidPanel دریافت و بررسی کنید.
- سیستم باید سرویس Javid Node Controller موجود، **فعال و سالم** داشته باشد.
- روی VPS در حال ارائه سرویس حیاتی، بدون پنجره نگهداری اجرا نکنید.

## مرحله اول — طرح بدون تغییر سیستم

```bash
git clone https://github.com/wisealii/JavaidPanel.git
cd JavaidPanel
python3 tools/upgrade-control-plane.py --plan
```

این دستور نسخه و فایل‌های سورس، مجوزهای config و سرویس موجود را بررسی می‌کند. سرویس را قطع یا فایل‌ها را تغییر نمی‌دهد.

## مرحله دوم — اعمال ارتقا

```bash
sudo python3 tools/upgrade-control-plane.py --apply
```

روند اجرای امن:

1. بررسی سلامت کنترلر فعلی از آدرس داخلی `127.0.0.1:9443/healthz`.
2. بررسی تمام فایل‌های جدید و نحو Python.
3. ایجاد کپی موقت سورس جدید در همان فایل‌سیستم.
4. تغییرنام سورس قبلی به پوشهٔ backup منحصربه‌فرد.
5. جایگزینی سورس جدید و راه‌اندازی مجدد سرویس.
6. چند بار بررسی سلامت API.
7. اگر مشکل بود، بازگرداندن سورس پیشین و راه‌اندازی مجدد.
8. حفظ backup برای بازبینی یا بازیابی دستی بعدی.

**این ارتقا کاملاً اتمیک نیست:** بین دو تغییرنام پوشه، وقفه کوتاه وجود دارد. اگر دیسک از دسترس خارج شود یا سرور خاموش شود، ممکن است بازیابی دستی نیاز باشد. در حالت شکست restart/health، اسکریپت تلاش می‌کند سورس قدیمی را بازگرداند.

## مرحله سوم — تأیید سرویس

```bash
sudo systemctl status javid-node-control.service
curl -fsS http://127.0.0.1:9443/healthz
```

همچنین از صفحه `/admin/nodes` در تونل SSH وضعیت heartbeat نودها را بررسی کنید. صرف پاسخ healthz نشان‌دهندهٔ سالم‌بودن تونل VPN نیست.

## محدودیت‌ها

- تغییرات schema دیتابیس نیازمند migration مستقل، backup و rollback تست‌شده است.
- این ابزار سرویس اصلی Gateway/پنل را ارتقا نمی‌دهد.
- بررسی و اتصال حساب مدیر پنل اصلی به داشبورد Javid Node هنوز انجام نشده است.
- تست‌ها در GitHub Actions روی فایل‌سیستم موقت اجرا می‌شوند؛ تست استقرار زنده VPS هنوز لازم است.
