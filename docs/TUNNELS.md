# تونل‌ها در JavaidPanel

JavaidPanel قرار است ساخت ارتباط بین دو VPS را با تنظیمات مشخص، اسکریپت نصب مستقل برای هر سمت و امکان عیب‌یابی ساده کند.

## روش‌های مطرح‌شده
WireGuard، SSH Forwarding، GRE/IPIP، VXLAN، OpenVPN Site-to-Site، gRPC و ابزارهای رلهٔ دیگر در مسیر بررسی قرار دارند.

**این فهرست کاتالوگ هدف/بررسی است، نه ادعای عملیاتی‌بودن همهٔ موارد.** برای هر روش باید مشخص شود چه باینری و نسخه‌ای استفاده می‌شود و آیا نصب دوطرفه، حذف، برگشت و مانیتورینگ واقعاً کار می‌کند یا نه.

## معیارهای آماده‌شدن هر روش
- اعتبارسنجی IP و پورت
- تولید اسکریپت‌های مستقل برای هر سرور
- بررسی وابستگی‌ها و بازبودن پورت‌ها
- اجرای مجدد بدون خراب‌کردن تنظیمات قبلی
- حذف امن و پشتیبان‌گیری
- تست واقعی اتصال و قطع/وصل بین دو VPS
