# عیب‌یابی JavaidPanel

## قبل از بررسی

نسخهٔ سورس و سیستم‌عامل، مدل VPS، زمان بروز خطا و **بخش غیرمحرمانه** پیام خطا را ذخیره کنید. رمزها، private key، URLهای دارای توکن یا اطلاعات شخصی را در Issue عمومی نگذارید.

## نصب‌کننده خطای «Unsupported OS» می‌دهد

این نسخه فقط Ubuntu 24.04 و Debian 12/13 روی x86_64 را در سطح کد می‌پذیرد. برای سیستم‌های دیگر، سرور را عوض کنید؛ تغییر دستی شرط نسخه راه‌حل امن نیست.

## خطای «SHA-256 mismatch»

اجرای فایل دانلودشده متوقف شده است. دلیل می‌تواند فایل ناقص، تغییر منبع یا ناسازگاری نسخه باشد. **کنترل هش را غیرفعال نکنید.** مخزن و هش پین‌شده را مقایسه و مشکل را گزارش کنید.

## خطای دسترسی root یا systemd

`sudo` و systemd فعال لازم‌اند. Docker container بدون systemd، محیط مناسب نصب مستقیم جاری نیست.

## کمبود RAM/فضای آزاد

مقادیر را با `free -h` و `df -h /opt` بررسی کنید. پیش از هر تغییر، backup بگیرید.

## خطای SSL / Let's Encrypt

- DNS دامنه و IP سرور را بررسی کنید.
- روش ACME، فایروال و اشغال پورت را کنترل کنید.
- زمان سیستم و زنجیرهٔ گواهی را بررسی کنید.
- اگر سرویس هنوز بالا نیست، نخست سلامت سرویس را چک کنید.

[راهنمای SSL](SSL.md)

## بعد از نصب پنل در دسترس نیست

```bash
sudo systemctl list-units --type=service | grep -iE 'javid|vpn|gateway' || true
sudo ss -lntup
```

برای خواندن لاگ، نام واقعی سرویس را از `systemctl list-units` پیدا کنید و `journalctl -u SERVICE_NAME --since '30 minutes ago'` را اجرا کنید. پیش از به‌اشتراک‌گذاری، اطلاعات حساس را پاک کنید.

## نود آنلاین نمی‌شود

عامل جدید Javid Node هنوز تکمیل نشده است. برای نودهای پایه، ابتدا نسخه، دسترسی شبکه، TLS و اسناد پشتیبانی هسته را بررسی کنید. نود را فقط وقتی آنلاین بشمارید که heartbeat معتبر وجود داشته باشد.

## صفحه دمو را با پنل واقعی اشتباه نگیرید

`docs/demo.html` فقط نمایش UI با داده نمونه است. هیچ API، سرور، پرداخت یا تونل را اجرا نمی‌کند.
