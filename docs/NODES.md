# راهنمای نودها در JavaidPanel

## نود چیست؟

نود یک سرور مستقل است که در کنار سرور مرکزی، بخشی از سرویس شبکه را اجرا می‌کند. هدف JavaidPanel مدیریت چند VPS از یک محل است، بدون اینکه کلید مدیریتی اصلی به همه سرورها داده شود.

### دو مسیر متفاوت — آن‌ها را اشتباه نگیرید

1. **نودهای پایه:** بخشی از موتور یکپارچه‌سازی قدیمی در `installer/core.sh` است. قابلیت/دستور فعال‌سازی دارد، ولی عملکرد چندسروری آن روی VPS واقعی تأیید نشده است.
2. **Javid Node اختصاصی:** عامل مستقل با توکن کوتاه‌عمر، اتصال TLS معتبر و گزارش سلامت؛ **هنوز منتشر نشده است** و `node-agent-install.sh` عمداً نصب آن را مسدود می‌کند.

## مسیر فعلی نودهای پایه

روی VPS **که پنل از قبل نصب شده** و پس از بررسی کد:

```bash
curl -fsSL https://raw.githubusercontent.com/wisealii/JavaidPanel/main/install.sh | sudo bash -s -- --enable-nodes
```

**این فرمان عامل Javid Node جدید را نصب نمی‌کند** و به‌تنهایی ایجاد سرور نود یا اتصال تأییدشده را تضمین نمی‌کند. قبل از هر نصب عملی، از کنترلر و نودها بکاپ بگیرید.

### نصب‌نکردن عامل نمایشی

```bash
bash node-agent-install.sh --check
```

دستور بالا فقط بررسی اولیه را انجام می‌دهد. **نصب عامل جدید تا وجود daemon واقعی و فرآیند ثبت معتبر غیرفعال است.**

## تجربه کاربری هدف: «اتصال نود»

1. در پنل گزینه **نودها → اتصال نود** باز شود.
2. نام سرور، IPv4/IPv6، منطقه، پورت و نوع ارتباط ثبت شود.
3. پنل یک شناسه و توکن **یک‌بارمصرف، زمان‌دار و قابل ابطال** بسازد.
4. دستور نصب اختصاصی با شناسه و آدرس معتبر پنل نمایش داده شود؛ توکن در URL عمومی قرار نگیرد.
5. روی VPS نود، پس از بازبینی اسکریپت، همان دستور اجرا شود.
6. عامل با TLS معتبر ثبت شود؛ سپس کلید/هویت جداگانهٔ خود را دریافت کند.
7. پنل فقط پس از دریافت heartbeat امضاشده وضعیت «آنلاین» نمایش دهد.
8. در صورت خطا، توکن منقضی/ابطال و پاسخ واضح به مدیر داده شود.

این **طرح توسعه** است، نه قابلیت آمادهٔ نسخه فعلی. جزییات: [ثبت امن نود](NODE_ENROLLMENT.md).

## نکات امنیتی

- هر VPS هویت منحصربه‌فرد و حداقل سطح دسترسی داشته باشد.
- توکن ثبت در دیتابیس فقط به شکل **هش** ذخیره شود؛ یک‌بار مصرف باشد.
- IP به‌تنهایی هویت معتبر نیست؛ تغییر IP نباید بی‌دلیل کلید خصوصی را افشا کند.
- انتقال فرمان از رابط به کاربر باید با ارتباط HTTPS انجام شود.
- حذف نود، ابطال دسترسی و بازیابی باید قابل ردگیری باشند.
- UI بین «در انتظار نصب»، «در حال ثبت»، «آنلاین»، «قطع»، «منقضی» و «خطا» تفاوت بگذارد.
