# مدیریت نودها در JavaidPanel

## نوع نودهای موجود

در هستهٔ پایهٔ AlirezaPanel مسیر مدیریت نود با تنظیمات پنل و دستور `--enable-nodes` وجود دارد. اما عامل مستقلی به نام **Javid Node** با اتصال خودکار و mTLS در نسخه فعلی منتشر نشده است.

برای فعال‌کردن ماژول پایه روی **سرور دارای پنل نصب‌شده**:

```bash
curl -fsSL https://raw.githubusercontent.com/wisealii/JavaidPanel/main/install.sh | sudo bash -s -- --enable-nodes
```

سپس باید مراحل افزودن و احراز هویت نود را از داخل UI هستهٔ پایه بررسی کنید. این دستور به‌تنهایی گواهی اتصال یا توکن معتبر نود صادر نمی‌کند.

## هدف معماری
یک کنترلر مرکزی برای مدیریت سرورهای متعدد و عامل سبک روی هر VPS در نظر گرفته شده است. فایل `node-agent-install.sh` در ریشهٔ مخزن فعلی وجود دارد.

## مواردی که باید قبل از استفاده عملی تأیید شوند
1. روش ثبت و احراز هویت عامل در کنترلر و نحوه ابطال اعتبار
2. امن‌بودن ارتباط و تأیید گواهی TLS
3. گزارش سلامت و سازوکار بازاتصال پس از قطعی شبکه
4. ترتیب همگام‌سازی کاربران و اینباندها بدون حذف ناخواستهٔ اطلاعات
5. پشتیبان‌گیری، حذف نود، بازیابی و کنترل نقش مدیران

## روش بررسی امن
- اسکریپت را ابتدا بخوانید: `less node-agent-install.sh`
- ساختار Bash را بررسی کنید: `bash -n node-agent-install.sh`
- فقط با سرور آزمایشی و حساب با کمترین سطح دسترسی تست کنید.

**توجه:** وجود فایل عامل به معنی تأیید عملی mTLS، همگام‌سازی امن یا قابلیت استفادهٔ تولیدی نیست.
