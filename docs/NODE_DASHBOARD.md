# راه‌اندازی صفحه «اتصال نود» در JavaidPanel

**وضعیت: مرحله چهارم توسعه · 1.1.106-dev**. این صفحه از API کنترلر و نودهای واقعی استفاده می‌کند؛ دادهٔ ساختگی ندارد. اما هنوز در رابط Gateway اصلی ادغام نشده و روی VPS واقعی تست نشده است.

## ۱. نصب کنترلر در سرور مرکزی

در VPS **آزمایشی** دارای Python 3.10+ و systemd، پس از بازبینی سورس:

```bash
git clone https://github.com/wisealii/JavaidPanel.git
cd JavaidPanel
sudo bash tools/install-control-plane.sh --check
sudo bash tools/install-control-plane.sh --install
curl http://127.0.0.1:9443/healthz
```

برای امنیت، API و داشبورد روی `127.0.0.1:9443` اجرا می‌شوند. روی اینترنت پورت 9443 را باز نکنید و `/admin/` را از Nginx منتشر نکنید.

**توجه:** نصب‌کنندهٔ فعلی از بازنویسی سرویس موجود جلوگیری می‌کند؛ برای ارتقای نسخهٔ قبلی باید دستور ارتقای ایمن با بکاپ/rollback اضافه شود. فایل‌های نصب‌شده را بی‌دلیل دستکاری نکنید.

## ۲. ایجاد یک SSH Tunnel از کامپیوتر خودتان

```bash
ssh -L 9443:127.0.0.1:9443 USER@CONTROL_VPS
```

ترمینال SSH را باز نگه دارید. سپس در مرورگر **همان کامپیوتر** وارد شوید:

```text
http://127.0.0.1:9443/admin/nodes
```

این HTTP از داخل تونل رمزگذاری‌شده SSH انتقال می‌یابد، نه به‌طور مستقیم روی شبکه عمومی.

## ۳. ورود به بخش اتصال نود

در سرور کنترلر، فقط برای مدیر دارای دسترسی sudo:

```bash
sudo cat /etc/javid-panel/node-control.json
```

مقدار `admin_token` را **محرمانه** بردارید و در فیلد ورود داشبورد قرار بدهید؛ فایل علاوه بر آن، کلید اصلی کنترلر هم دارد. آن را به کسی یا به مرورگر کپی نکنید؛ فقط مقدار توکن موردنظر را منتقل کنید. محتویات فایل را در Issue، عکس یا چت عمومی ارسال نکنید.

توکن در `localStorage` یا کوکی نوشته نمی‌شود و با بستن صفحه پاک می‌شود. دکمه «پاک‌کردن دسترسی» نیز آن را از حافظه برنامه پاک می‌کند.

## ۴. ثبت IP و ساخت دستور اختصاصی

در صفحه «افزودن سرور»:

1. **نام نود** را وارد کنید، مثل Germany-01.
2. **IP یا دامنهٔ VPS نود** را وارد کنید.
3. **دامنه عمومی HTTPS کنترلر** را وارد کنید؛ مثلا `https://panel.example.org`.
4. مدت اعتبار توکن را بین **۱ تا ۳۰ دقیقه** انتخاب کنید.
5. «ایجاد نود و دستور اختصاصی» را بزنید.

برنامه از API واقعی توکن ثبت را یک بار دریافت می‌کند، سپس **دستور نصب** و **توکن** را **جداگانه** نمایش می‌دهد. توکن در URL یا آرگومان Shell قرار داده نمی‌شود.

## ۵. نصب عامل روی VPS نود

روی VPS دوم، دستور اختصاصی نمایش داده‌شده را پس از مطالعه اجرا کنید؛ سپس توکن را در ورودی مخفی وارد نمایید. عامل فقط گزارش سلامت را ارسال می‌کند؛ **تونل VPN ایجاد نمی‌کند**.

## ۶. کنترل وضعیت نود

- `pending`: نود ثبت شده ولی عامل هنوز نصب/ثبت نشده.
- `claimed`: توکن مصرف شده اما heartbeat معتبر هنوز دریافت نشده.
- `online`: heartbeat تازه و معتبر دریافت می‌شود.
- `offline`: آخرین heartbeat منقضی شده.
- `revoked`: دسترسی نود باطل شده است.

صفحه هر ۱۵ ثانیه از API داده تازه می‌گیرد و با دکمه «ابطال» می‌توانید دسترسی نود را ببندید. هیچ وضعیت آنلاینی بدون heartbeat معتبر از سمت کنترلر ساخته نمی‌شود.

## نکات مهم ایمنی

- داشبورد **عمومی نیست**؛ آن را در Nginx یا reverse proxy عمومی فعال نکنید.
- اگر پورت 9443 روی کامپیوتر شما مشغول است، ابتدا پورت محلی را آزاد کنید؛ این نسخه برای همان نشانی پیش‌فرض تست شده است.
- اطلاعات مدیریتی را در عکس، تاریخچه Shell یا گزارش عمومی افشا نکنید.
- درخواست‌های مرورگر دارای توکن Bearer هستند و نیاز به اتصال همان مبدا localhost دارند.
- API فعلاً احراز هویت مدیر با توکن ثابت دارد؛ RBAC، حساب چندمدیر، یکپارچه‌سازی SSO، mTLS و گردش کلید هنوز در برنامه توسعه‌اند.
- این صفحه **پنل اصلی یکپارچه نیست** و روی VPS واقعی یا در محیط تولید تأیید نشده است.
